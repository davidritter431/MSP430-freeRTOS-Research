# FreeRTOS-Research on MSP430FR5994

Author: David Ritter

## Overview

This repository documents my exploration of FreeRTOS on the Texas Instruments MSP430FR5994 microcontroller using Code Composer Studio (CCS).

The goal of this project is to develop a strong foundation in:
- Embedded C programming
- Real-Time Operating Systems (RTOS)
- Task Scheduling
- Static and dynamic memory allocation
- Context switching
- Inter-task communication
- Embedded systems architecture

This work serves as preparation for future research in embedded systems, robotics, and embedded AI.
